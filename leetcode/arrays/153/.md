# 153. Encontrar o Mínimo em um Array Rotacionado

**Médio**

Suponha que um array de tamanho `n`, ordenado em ordem crescente, seja rotacionado entre 1 e `n` vezes. Por exemplo, o array `nums = [0,1,2,4,5,6,7]` pode se tornar:

- `[4,5,6,7,0,1,2]` se for rotacionado 4 vezes.
- `[0,1,2,4,5,6,7]` se for rotacionado 7 vezes.

Observe que rotacionar um array `[a[0], a[1], a[2], ..., a[n-1]]` 1 vez resulta em:  
`[a[n-1], a[0], a[1], a[2], ..., a[n-2]]`.

Dado o array `nums`, que está **ordenado e rotacionado**, contendo apenas valores **únicos**, retorne o **menor elemento** do array.

Você deve escrever um algoritmo com complexidade de tempo **O(log n)**.

---

| Exemplo   | Entrada                  | Saída | Explicação                                                   |
| --------- | ------------------------ | ----- | ------------------------------------------------------------ |
| Exemplo 1 | `nums = [3,4,5,1,2]`     | `1`   | O array original era `[1,2,3,4,5]`, rotacionado 3 vezes.     |
| Exemplo 2 | `nums = [4,5,6,7,0,1,2]` | `0`   | O array original era `[0,1,2,4,5,6,7]`, rotacionado 4 vezes. |
| Exemplo 3 | `nums = [11,13,15,17]`   | `11`  | O array já está ordenado (rotacionado `n` vezes).            |

---

### Restrições

- `n == nums.length`
- `1 <= n <= 5000`
- `-5000 <= nums[i] <= 5000`
- Todos os elementos de `nums` são **únicos**
- `nums` está ordenado e rotacionado entre `1` e `n` vezes
