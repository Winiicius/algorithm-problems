# 739. Daily Temperatures

**Médio**

Dado um array de inteiros `temperatures`, onde cada valor representa a temperatura diária, retorne um array `answer` tal que `answer[i]` seja o número de dias que você precisa esperar após o dia `i` para encontrar uma temperatura mais quente.

Se não existir um dia futuro com temperatura maior, então `answer[i]` deve ser `0`.

---

| Exemplo   | Entrada                                    | Saída               |
| --------- | ------------------------------------------ | ------------------- |
| Exemplo 1 | `temperatures = [73,74,75,71,69,72,76,73]` | `[1,1,4,2,1,1,0,0]` |
| Exemplo 2 | `temperatures = [30,40,50,60]`             | `[1,1,1,0]`         |
| Exemplo 3 | `temperatures = [30,60,90]`                | `[1,1,0]`           |

---

### Restrições

- `1 <= temperatures.length <= 10⁵`
- `30 <= temperatures[i] <= 100`
