# 84. Maior Retângulo no Histograma

**Difícil**

Dado um array de inteiros `heights` representando as alturas das barras de um histograma, onde a largura de cada barra é `1`, retorne a **área do maior retângulo** que pode ser formado dentro do histograma.

---

| Exemplo   | Entrada                   | Saída | Explicação                                                            |
| --------- | ------------------------- | ----- | --------------------------------------------------------------------- |
| Exemplo 1 | `heights = [2,1,5,6,2,3]` | `10`  | O maior retângulo possível (na área destacada) tem área igual a `10`. |
| Exemplo 2 | `heights = [2,4]`         | `4`   | O maior retângulo possível tem área `4`.                              |

---

### Restrições

- `1 <= heights.length <= 10^5`
- `0 <= heights[i] <= 10^4`
