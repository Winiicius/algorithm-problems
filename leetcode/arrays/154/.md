# 154. Encontrar o Mínimo em um Array Rotacionado II

**Difícil**

Suponha que um array de tamanho `n`, ordenado em ordem crescente, seja rotacionado entre 1 e `n` vezes. Por exemplo, o array `nums = [0,1,4,4,5,6,7]` pode se tornar:

- `[4,5,6,7,0,1,4]` se for rotacionado 4 vezes.
- `[0,1,4,4,5,6,7]` se for rotacionado 7 vezes.

Observe que rotacionar um array `[a[0], a[1], a[2], ..., a[n-1]]` 1 vez resulta em:  
`[a[n-1], a[0], a[1], a[2], ..., a[n-2]]`.

Dado o array `nums`, que está **ordenado e rotacionado** e **pode conter elementos repetidos**, retorne o **menor elemento** do array.

Você deve **reduzir ao máximo** o número total de operações.

---

| Exemplo   | Entrada              | Saída |
| --------- | -------------------- | ----- |
| Exemplo 1 | `nums = [1,3,5]`     | `1`   |
| Exemplo 2 | `nums = [2,2,2,0,1]` | `0`   |

---

### Restrições

- `n == nums.length`
- `1 <= n <= 5000`
- `-5000 <= nums[i] <= 5000`
- `nums` está ordenado e rotacionado entre `1` e `n` vezes
